# 볼테어 같은 금고 앱 — 소스 코드

Vaultaire에서 영감을 받은 사진·파일 금고 앱의 소스 코드입니다. 앱 안에서 '코드' 탭으로 보여주는 실제 소스와 같은 내용입니다.

## 포함된 내용

- 패턴마다 별도의 금고 (5×5 패턴, 패턴이 곧 그 금고의 열쇠)
- 금고 안에서 사진·파일 넣기, 보기, 꺼내기, 삭제
- 해시 체인 백업 (패키지 v2: PBKDF2-HMAC-SHA-256, 파일별 무작위 논스 HMAC 키스트림 + 인증 태그)
- 회복 문구 (9단어, 패턴을 감싼 암호화 봉투)
- 모바일 웹 앱 형태 (홈 화면 웹 앱, 앱스토어 네이티브 앱이 아님)

## 정직한 주의사항

- 금고에 저장된 파일 자체는 패턴 확인(verify-only) 방식으로 가려지며, 패턴에서 파생된 키로 저장 시 암호화되는 것은 백업 패키지입니다. 앱 화면에도 이 점이 그대로 적혀 있습니다.
- 이 저장소에는 금고 데이터, 사용자 파일, 패턴, 회복 문구가 포함되어 있지 않습니다. 코드만 포함되어 있습니다.
- 이 코드는 Muse space 런타임(@hatch/space-sdk 등)에 의존하므로, 이 파일들만으로는 그대로 실행되지 않을 수 있습니다. 실행 환경은 앱 자체를 기준으로 확인해 주세요.

## 파일 구성

- `client/` — 화면, 패턴 패드, 백업·회복 로직, 미리보기
- `server/` — 금고·백업·회복 관련 서버 액션과 스키마
- `drizzle/` — 데이터베이스 마이그레이션
- `DATA-PLAN.md` — 데이터 설계 문서
- `space.json` — 앱 메타데이터
